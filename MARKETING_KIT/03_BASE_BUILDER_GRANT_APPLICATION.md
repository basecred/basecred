### Question 1: What is your project and what problem does it solve?
BaseCred is a decentralized on-chain reputation and content curation platform built natively for Base. Traditional airdrops suffer from mercenary sybils and spam. BaseCred solves this by auditing genuine on-chain footprint (gas burnt, L1 age, Base nonce, and Basename ownership) to allocate verifiable credits ($CRED). Furthermore, it introduces the "Weekly Base Spotlight" where users receive 1 non-stackable pass per week to endorse high-value content highlighting @base, turning the community into an organic marketing army for the Base ecosystem.

### Question 2: How does your project support the Base ecosystem?
1. **Basename Adoption:** Owning a .base.eth domain grants substantial credit boosts, driving primary Basename registrations.
2. **Promoting Key Protocols:** The scoring engine rewards historical usage of Base-native protocols (Aerodrome, Uniswap on Base, Moonwell).
3. **High-Quality Educational Content:** By requiring endorsements to tag @base and discuss Base development, we incentivize creators to publish high-effort research, tutorials, and analytics.
4. **100% Open Source:** Built as a public good with MIT license.

### Question 3: What will the grant funds be used for?
The funds (1-2 ETH) will be used to subsidize gas fees for the upcoming MerkleDistributor claim contracts on Base Mainnet, fund the weekly Creator Hall of Fame rewards, and maintain the public API nodes.
